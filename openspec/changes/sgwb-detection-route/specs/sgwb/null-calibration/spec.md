## Purpose

Turn the detection statistic into a calibrated one by measuring, empirically, how large it gets when
no inter-pulsar correlation is present — so a reported Bayes factor carries a false-alarm
probability rather than only a qualitative adjective.

## ADDED Requirements

### Requirement: The detection statistic has an empirical null distribution

Before any detection claim is made on a dataset, the system SHALL produce a null distribution of the
detection statistic on that same dataset, generated by destroying the inter-pulsar correlation
structure while preserving the per-pulsar noise, sampling geometry and data volume.

#### Scenario: Null realisations are generated

- **WHEN** null calibration is requested for a dataset
- **THEN** the system produces an ensemble of statistic values computed on realisations in which the
  correlation structure has been destroyed, and records the ensemble alongside the dataset's own
  statistic value

#### Scenario: Per-pulsar properties preserved

- **WHEN** a null realisation is constructed
- **THEN** each pulsar's noise parameters, observation epochs and residual values are unchanged
  relative to the real analysis, and only the correlation assignment differs

### Requirement: Significance is reported as a false-alarm probability

The reported result SHALL express significance as the fraction of null realisations whose statistic
equals or exceeds the observed value, together with the number of realisations, and SHALL state the
resolution floor when the observed value exceeds all of them.

#### Scenario: Observed value inside the null range

- **WHEN** the observed statistic is exceeded by at least one null realisation
- **THEN** the reported p-value is the exceedance fraction with its binomial uncertainty

#### Scenario: Observed value beyond every null realisation

- **WHEN** no null realisation reaches the observed statistic
- **THEN** the result is reported as an upper bound `p < 1/N` for the ensemble size `N`, and is not
  reported as a smaller number than the ensemble can resolve

### Requirement: Calibration is validated where the answer is known

The null-calibration machinery SHALL be exercised on a dataset with a known injected signal and on a
matched dataset without one, and SHALL give the expected qualitative answer in each case, before
being applied to real data.

#### Scenario: Known injection

- **WHEN** null calibration runs on the MDC2 array analysis with its known injected GWB
- **THEN** the observed statistic falls in the extreme upper tail of the null ensemble

#### Scenario: No injection

- **WHEN** null calibration runs on a matched dataset with no correlated signal
- **THEN** the observed statistic falls within the bulk of the null ensemble, and the recovered
  p-value distribution is consistent with uniform

### Requirement: The calibration ensemble size is planned and its cost bounded

The number of null realisations SHALL be chosen and recorded in advance from the resolution needed
for the intended claim, and the calibration SHALL use a per-realisation procedure cheap enough to
make that ensemble feasible on the available compute.

#### Scenario: Ensemble sized before running

- **WHEN** null calibration for a dataset is planned
- **THEN** the target ensemble size, the resulting p-value resolution and the estimated compute cost
  are recorded before realisations are launched

#### Scenario: Ensemble not affordable

- **WHEN** the ensemble needed for the intended claim is not affordable on the available compute
- **THEN** the claim is downgraded to the resolution the affordable ensemble supports, and the
  limitation is stated with the result
